# フェーズ2 設定手順（LINE Webhook ／ Gmail転送）

公開URL：`https://inquiry-router.vercel.app`

## 1. LINE の Webhook URL を設定する（5分）

1. https://developers.line.biz/console/ → 案件5のチャネル →「Messaging API設定」タブ
2. 「Webhook設定」→ Webhook URL に次を入力して「更新」
   ```
   https://inquiry-router.vercel.app/api/line/webhook
   ```
3. 「検証」ボタン →「成功」と出ればOK（署名検証を通過した証拠）
4. 同じ画面で次をオンにする
   - **Webhookの利用：オン**
   - **Webhookの再送：オン**（サーバーが一時的に落ちていても、LINEが後から送り直してくれる。重複はサーバー側で弾く）

## 2. Gmail → GAS の転送を設定する（10分）

テスト用 Gmail アカウントでログインした状態で行う。

1. https://script.google.com/ →「新しいプロジェクト」→ 名前を `問い合わせ転送` に変更
2. 最初から入っている `function myFunction() {}` を消して、`gas/mail-forwarder.gs` の中身を貼り付けて保存（⌘S）
   - 中身のコピー（ターミナルで実行）：`pbcopy < "/Users/aoi/AIエンジニア講座/模擬案件/案件５/gas/mail-forwarder.gs"`
   - 先頭の `!` は Claude Code の入力欄で実行するときだけ付ける。普通のターミナルでは付けない
3. 左の歯車「プロジェクトの設定」→ 一番下「スクリプト プロパティ」→「スクリプト プロパティを追加」で2つ登録

   | プロパティ | 値 |
   |---|---|
   | `INGEST_URL` | `https://inquiry-router.vercel.app/api/mail/ingest` |
   | `INGEST_SECRET` | 64文字の英数字（下のコマンドでコピーした値） |

   `INGEST_SECRET` の値は、**ターミナルで**次のコマンドを実行してコピーし、値の欄に⌘Vで貼る（コマンド自体は貼らない）
   ```bash
   grep '^MAIL_INGEST_SECRET=' "/Users/aoi/AIエンジニア講座/模擬案件/案件５/.env.local" | cut -d= -f2- | tr -d '\n' | pbcopy
   ```
   貼れたか不安なときは、エディタで `checkSecret` を実行し「長さ=64」と出ることを確認する

4. 左の「エディタ」に戻る → 上部の関数選択で **`setup`** を選んで「実行」
5. 「承認が必要です」→「権限を確認」→ アカウントを選択
   - 「Googleはこのアプリを確認していません」と出たら「詳細」→「問い合わせ転送（安全ではないページ）に移動」→「許可」
   - 自分で作ったスクリプトなので問題ない（Gmailの読み取りと外部への送信の権限を求められる）
6. 実行ログに「セットアップ完了」と出ればOK
7. 左の時計アイコン「トリガー」→ `pollInbox`（時間主導型・1分ごと）が1つあることを確認

## 3. 動作確認

1. 自分の個人LINEから、公式アカウントにメッセージを1通送る（例：「駐車場付きの賃貸マンションを探しています。」）
2. 別のメールアドレスから、テスト用 Gmail にメールを1通送る（例：件名「物件について」、本文「中古マンションの購入を検討しています。」）
3. 2分ほど待ってから Claude Code に「送りました」と伝える → DB に2件入っているか確認する
