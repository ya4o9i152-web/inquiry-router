# 問い合わせ自動仕分け 運用マニュアル（スタッフ向け）

メールと LINE に届いたお問い合わせは、AI が内容を読んで Slack の専用チャンネルに自動で届けます。
**お客様への返信は、これまで通りメール・LINE から行ってください。** Slack は「確認と振り分け」のための場所です。

## 毎日の流れ

1. Slack の各チャンネルを確認する

   | チャンネル | 届くもの | 目安 |
   |---|---|---|
   | #問合せ-賃貸 | お部屋探し、賃貸契約・更新・退去・敷金のご相談 | 全体の約50% |
   | #問合せ-売買 | 購入・売却・査定・投資用物件・住宅ローン | 約20% |
   | #問合せ-内見 | 内見の日程調整・お申し込み | 約20% |
   | #問合せ-クレーム | 入居中のお部屋のトラブル・苦情（部長の LINE にも届きます） | 約10% |
   | #問合せ-その他 | 不動産と関係のない内容、営業メール、⚠️未分類 | 少数 |

2. 投稿の見方

   ```
   🏠 賃貸のお問い合わせ                     ← AIが判定したカテゴリ
   > 駅近の1LDKを探しています…               ← お客様の本文
   LINE｜山田 花子　/　受信 10/4 21:03　/　AI判定：…（確信度 high）
   返信は LINE公式アカウントのチャット から    ← 返信する場所
   ```

3. 対応したら、その投稿に ✅ のリアクションを付ける（誰が対応したか、ほかの人にもわかるように）

## こんなときは

| 状況 | 対応 |
|---|---|
| **⚠️ 未分類（AI判定に失敗・要確認）** が届いた | AI が一時的に使えなかった問い合わせです。内容を読んで、担当者が対応してください。クレームの可能性もあるため、部長にも通知されています |
| カテゴリが間違っている | そのまま正しい担当者が対応して構いません。間違いが続く場合は、投稿のリンクを開発担当に送ってください（AI の指示を調整します） |
| 部長の LINE に通知が来たが、クレームではなかった | 「迷ったら通知する」設計なので、ときどき起こります。頻繁に起きる場合は開発担当へ |
| 「（画像が送信されました）」と表示される | LINE で画像やスタンプが送られています。中身は LINE公式アカウントのチャット画面で確認してください |
| お客様から「送ったのに返事がない」と言われた | Slack のチャンネルを検索してください。見つからない場合は開発担当へ（送信日時とお客様名を伝える） |
| Slack にしばらく何も届かない | 普段より極端に少ない場合は開発担当へ連絡してください |

## 部長に届く LINE 通知

- 【緊急】クレームの可能性がある問い合わせ … 受信から1分以内（実測は約6秒）に届きます
- 【要確認】AI が分類できなかった問い合わせ … AI が使えないときに、念のため届きます
- 夜間・休日も届きます
